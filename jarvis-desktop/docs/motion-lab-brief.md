# Motion Lab development brief

User requests Claude Motion Lab for motion work. Likely reference is Florence's “Opus 5.5 Motion Lab: Make Claude Animate Like a Studio”, a creator guide/showcase, rather than a verified Anthropic product or licensed SDK.

References: https://x.com/flxrnc/status/2105311836190978392 (direct page unavailable during root lookup); https://createmotion.io/articles/opus-5-5-motion-lab-make-claude-animate-like-a-studio-7253d5ce6242/ (author/title/source attribution). An indexed mirror describes numbered timing, iterative frame inspection and deterministic code animation. This is inspiration, not permission to copy its text/artwork/source.

Implement original offline motion with explicit durations/easing/spring parameters, anticipation/follow-through, seeded randomness and frames derived from time. Render same frame identically; inspect representative frames and loop seams using contact sheets when tooling permits. Use bounded quality/resource profiles, reduced-motion alternatives and real export capabilities. Sound optional, synthesized locally only after user gesture; no autoplay or copied tracks.

Existing Canvas/SVG/CSS and locally bundled dependencies first. No CDN imports/fonts/remote media, no MotionLab cloud account, no additional service billing. Do not install an unidentified product or claim an integration absent a real connector. Any new library requires permissive commercial license review and local packaging by captain.

Worker motion owns MotionStudio/timing/presets; avatar owns AvatarStudio/pack editor. Keep schemas compatible; captain mounts screens and bundles styles. Artifact quality requires observed frame/browser evidence, not only typecheck or source assertions. Mark unavailable encoder, 3D and photoreal features honestly.
