# First Light character concept

Original generated concept artwork for review, based on Direction A in PET-CONCEPTS.md. Generated 17 October 2026 with the built-in image tool; cream body, indigo ears/tail, coral nose and mint hip marking. Not an approved final character or a complete sprite atlas.

The current concept renderer uses whole-artwork transforms for breathing, thinking and a completion greeting. These do not provide independently animated eyes, limbs or sixteen look directions. Production sprite assets must follow the v2 atlas contract and be validated before installation. This asset is bundled locally; no runtime image service is used.
